# Wenworks AI 共用视觉规范

品牌：Wenworks AI，https://ai.wenworks.app 。一个站，四个部分：首页（本周动态）、模型 `/models/`、Agent 导航 `/agents/`、工具精选 `/tools/`。

## 颜色

- 背景 #ffffff；文字 #171717；次要文字 #525252
- 浅底/行悬停 #f5f5f5，更浅的块用 #fafafa
- 边框 #e5e5e5，悬停时 #d4d4d4；主色和焦点环 #171717
- 唯一强调色是橙色 #ec5b13，按强弱依次为 #f07f45 #f5a77a #f9c9ac #fde4d4
- 整站基本是黑、白、灰，橙色只用在最重要的地方（"新"标记、当前项）
- 不用渐变、玻璃质感、发光，也不做深色模式

## 字体

- 正文 IBM Plex Sans，中文回退到系统字体
- 数字和代码用 IBM Plex Mono，开启 tabular-nums
- 正文 16px，行高 1.5；次要信息 14px

## 形状与间距

- 控件和卡片都是直角；用 1px #e5e5e5 的线分隔，基本不用阴影
- 浮层用 0 8px 24px rgb(0 0 0 / 6%)
- 间距 0.25 / 0.5 / 1 / 1.5 / 2 / 3 rem；控件高度 2.75rem

## 动效

- 页头进场 360ms，内容淡入 460ms，缓动曲线 cubic-bezier(0.22, 1, 0.36, 1)
- 悬停时上移 1px，过渡 180ms
- 支持 prefers-reduced-motion

## 共用页头

```
[Wenworks AI]   模型   Agent 导航   工具精选   |   本部分的栏目 …
```

- 高 3.5rem，白底，底部 1px #e5e5e5 边线
- "Wenworks AI" 字重 600，指向整个站的首页 `/`
- 三个入口指向 `/models/`、`/agents/`、`/tools/`；当前所在的部分加 aria-current="page"，首页不高亮任何一个
- 链接默认是次要文字色，悬停或当前页时变成正文色并显示下划线（下划线从左向右展开）
- 手机宽度下，本部分的栏目收进菜单按钮，三个入口始终显示；400px 以下入口间距收窄，再窄时可以横向滑动
- 样式只有一份，在 `shared/site-header.css`，由 `scripts/sync-shared.mjs` 同步到四个部分

## 各部分的补充

- **首页**：就是最新一期动态。从上到下是刊头（日期、一句话概括）、一排要点数字、正文；正文左边是栏目名，右边是内容，手机上叠成一栏。
- **模型**：内容区最大宽度 72rem；表格表头吸顶，放在可横向滚动的容器里；不用图标，不写营销文案。
- **工具精选**：语言切换在本部分栏目的最右；首页的五个板块是 tab 按钮，样式和页头链接一致；资源卡片保留封面图，直角。Curator（本地管理界面）沿用同一套颜色和直角。
- 橙色用在：首页刊头的日期、"榜首"那一格和第一梯队标签的顶线、"榜首更换"和"新"两个标记，以及梯队标签（五档由深到浅）。
