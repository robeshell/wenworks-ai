## 已实现

- 收录与编辑共用持久工作区；保存、刷新和继续对话保持同一会话。桌面内容/助手双栏，可调宽和收起；900px 以下切换内容/助手，完成状态温和播报。
- 工具、技能、项目、站点、提示词均可编辑；类型转换先展示字段差异，再采用或保留原内容。历史保留完整字段，撤销采用三方合并，保留随后手改内容。
- 自动暂存、明确保存版本、公开快照分别管理。保存草稿不更新公开目录；公开文件更新失败可重试，已有文件冲突时保留所有文件。
- Agent 针对最新草稿局部修改，支持连续对话和采用唯一待确认提案。整篇替换、翻译源变化和字段冲突进入预览。处理中可继续输入、排队或停止后续写。
- 首稿直接交付；润色和补英文作为主动操作。来源、消息、运行过程、失败与停止记录持久化。失败重试可复用已取得的证据。
- 发布后的类型/地址变化生成中英文静态旧地址入口，含无脚本可用链接；工具目标定位到目录对应资源。
